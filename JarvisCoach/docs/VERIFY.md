## VERIFY – 10 分钟验收清单（JarvisCoach）

本文件用于快速 Yes/No 验证 MVP 是否达标。

### 1. 权限

1.1 能请求麦克风与语音识别权限  
- [ ] 首次安装并启动 App，系统弹出麦克风权限对话框。  
- [ ] 紧接着弹出语音识别权限对话框。  
- [ ] 拒绝后重新启动 App 时不崩溃，并可在系统设置中重新打开权限。

### 2. 实时转写

2.1 转写实时出现（英文/中文至少一种稳定）  
- [ ] 启动 Session 后，对着手机说一段简短中文或英文句子。  
- [ ] 打开 Live HUD 右上角 Debug 折叠区，可以看到「最近一句转写」几乎实时更新。  
- [ ] 连续说两三句，转写不会明显卡死或停止更新。

### 3. 建议生成频率

3.1 Them 模式下，每 1–2 秒生成一条建议  
- [ ] Live HUD 中 Speaker 为 **Them**。  
- [ ] 模拟“对方”问问题，停顿 1 秒，看 HUD 中间是否在 1–2 秒内出现新建议。  
- [ ] 连续问两三个问题，建议会稳定更新且不会每个音节都触发（有节流去抖效果）。

### 4. 建议格式与内容

4.1 建议 <= 2 句、无问号、第一句直答（抽检 5 次）  
- [ ] 任意 Mode 下，连续抽样 5 次建议：  
  - [ ] 句子数量不超过 2 句。  
  - [ ] 不包含中文或英文问号（`？` / `?`）。  
  - [ ] 第一句直接回答对方问题，而不是反问或 Meta 说明。  

### 5. Mode 切换行为

5.1 Mode 切换会改变回答策略（至少 Pitch vs Sales）  
- [ ] 在 Home 页面选中 **Pitch** 模式，提问「你们和竞品差异？」观察建议偏向差异与价值解释。  
- [ ] 切换到 **Sales** 模式后重复同样问题，观察建议更偏向业务收益与下一步行动。  
- [ ] 两种模式下的语气和重点有明显差异。

### 6. Debug 折叠区

6.1 Debug 折叠区不显示 JSON，能清空缓存  
- [ ] Live HUD 右上角点击 Debug 折叠，展开内容只包含：  
  - 最近一句转写（纯文本）  
  - 最近更新时间 / 最近一次延迟（数字 + 文本，不含 JSON）  
  - Clear 按钮  
- [ ] 点击 Clear 后，再次说话前 Debug 区域的「最近一句」变为 `—` 或空。

### 7. Key 管理与安全

7.1 API key 不在 repo（检查 .gitignore）  
- [ ] 仓库根目录执行 `git status`（如使用 Git），确认 `ios/Config/Secrets.xcconfig` 未被跟踪。  
- [ ] 打开 `.gitignore` 文件，包含 `ios/Config/Secrets.xcconfig` 条目。  
- [ ] 代码中未出现硬编码的 `ANTHROPIC_API_KEY` 字符串或明显的密钥。  

7.2 不落盘转写  
- [ ] 搜索工程（排除构建产物）确认无将转写内容写入磁盘的代码。  
- [ ] Debug 区域仅展示内存中的最近一句转写，不提供“导出全部对话”入口。
