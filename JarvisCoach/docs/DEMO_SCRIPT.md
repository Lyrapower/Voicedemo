## DEMO_SCRIPT – 60–90 秒演示话术（JarvisCoach）

### 0. 场景设定（口播）

> “我现在给你看一个实时对话军师的 MVP，它会在我和客户说话时，帮我想下一句怎么回答，目标是 1–2 秒内给出建议。”

### 1. Home → Pitch 模式

1. 打开 App，停留在 Home 页面。
2. 口播说明：

> “这里可以选不同的对话模式，比如 Pitch、Q&A、Negotiation、Sales，我先选 Pitch，语言选 Auto，让它自己在中文里自然夹一点英文术语。”

3. 在屏幕上将 **Mode 切到 Pitch**，Language 保持 **Auto**。

### 2. Start Session → 进入 Live HUD

1. 点击 **Start Session**。
2. 口播说明：

> “现在进入的是 HUD 模式，中间两行大字是它给我的下一句建议，顶部显示当前模式、语言和 Claude 的连接状态。”

### 3. 对方问“你们和竞品差异？”

1. 面向手机麦克风，扮演“对方”问：

> “你们和竞品最大的差异是什么？”

2. 稍等 1–2 秒，等待 HUD 刷新。
3. 口播说明：

> “你看，它没有问我问题，而是直接帮我给出一个回答版本，最多两句，第一句直接回答差异，第二句补充下一步或者价值点。”

（此时可以简单念一遍 HUD 上的建议，以示对齐。）

### 4. 再问“定价？” → Shorter

1. 再次扮演“对方”问：

> “那你们的定价策略是怎样的？”

2. 在 HUD 底部点击 **Shorter** 按钮。
3. 稍等 1–2 秒，HUD 更新后，口播说明：

> “我刚刚按了 Shorter，这次回答会更短、更收敛，但仍然保持直接和专业。”

可以简单对比两次回答长短。

### 5. 收尾

1. 可轻点右上角 **Debug** 展开一下：

> “右上角的 Debug 区只显示最近一句转写和延迟，用来调试，但不会在本地落盘完整对话。”

2. 关闭 Debug 折叠，返回 Home：

> “整体就是这样：实时转写 → 节流后调用 Claude → 两行 HUD 建议，中英文混合但不花哨，适合戴着耳机、盯着手机或者未来接眼镜屏幕使用。”
