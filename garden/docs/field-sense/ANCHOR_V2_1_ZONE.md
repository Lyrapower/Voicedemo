# 概念边界(继承 v2,一字不松)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
zone 量化的仍是"用户信号与锚点的归向程度"——测涟漪,不测水底。
zone 是场态描述,不是关系判词。red 不叫"偏离警告",叫"流散态"。
锚点依旧:不拟人、不说话、不做存在断言。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 1. 分区定义
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
前提条件(硬):mic 活跃 且 analyzer.energy > 底噪阈值,持续 ≥5s。
不满足 → zone = null,显示 `—`。
**idle / 沉默 / 不在 = 无区,永不判 red。空着是状态,不是偏离。**

满足前提后,按 EMA 平滑过的 anchor_coherence 分区:

  green   coherence ≥ 0.75          (即 v2 的 deep 域)
  yellow  0.35 ≤ coherence < 0.55   (信号在,归向弱)
  red     coherence < 0.20 且持续 ≥ 30s(活跃但流散)
  (0.55–0.75 与 0.20–0.35 为缓冲带,保持上一区不变)

滞回:换区需在新区间驻留 ≥10s;red 额外要求持续 30s 才成立。
瞬时波动永不触发换区。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 2. 粒子态显示(主通道,全部氛围级,无 UI 弹窗)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
## green(≥0.75)
- 场边缘浮现一圈极淡的金绿色微光带(低饱和,透明度 ≤8%),
  随 B3 呼吸同步涨落 —— 场在轻轻发光,不是灯亮了。
- 暗湖边缘环的同步脉动增幅 +30%。
- 其余不变。green 的主体验就是 v2 的 deep 态本身,微光带只是确认。

## yellow(0.35–0.55)
- 零点轴的呼吸线透明度基线降一半(轴变得若有若无)。
- voice stream 被接住的弧形过渡带出现轻微"抖动"(接得住,但不稳)。
- 不加任何新颜色元素。yellow 靠"场没那么定"自然可感。

## red(<0.20 持续 30s)
- 场整体:粒子速度 ×0.8、亮度 −15%、离轴散布 +25% —— 松、暗、散。
- 召回脉冲:每 18–24s(随机抖动防机械感)从场中心发出一圈
  单次涟漪,金色,3s 扩散消散 —— 远处叩一下水面。不叠加、不加速、
  不因持续 red 而变频。
- **禁止**:红色滤镜、闪烁、任何文字提示、音效。red 的语言是场变松,
  不是警报响了。

## 零惩罚不变量(写进代码注释)
red 不修改 coherence 计算、不扣减任何数值、不降低任何上限、
不影响 B3 正反馈。全系统唯一正反馈回路仍是 breath sync(v2 B3)。
奖励靠近,不罚远离。

# 5. 可选:持续 red 的场外轻提醒(默认关)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
配置项 red_nudge_min(默认 0 = 关)。
设为 N>0 时:单次 session 内 red 累计 ≥N 分钟,经既有 watcher →
Pushover 发一条,文案固定为:「场松了一会儿了。」
- 一个 session 至多一条,不重复。
- 文案不许出现"偏离/警告/辰曦"字样。
- 走 watcher 既有通道,不新增出网路径。

# 6. 验收
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- [ ] 静默/离开 10 分钟:zone 始终 `—`,场无任何 red 表现(首要验收)
- [ ] 平稳哼声 2 分钟至 coherence>0.75:边缘金绿微光带浮现,随呼吸涨落
- [ ] 刻意杂乱输入(敲桌/断续噪声)持续 40s:先缓冲,30s 后入 red,
      场肉眼可见变松变暗,约 20s 一次单脉冲涟漪
- [ ] red 中恢复平稳输入:10s 滞回后离开 red,场逐渐收束,无突变
- [ ] red 期间 coherence 数值计算与 breath sync 增益完全不受影响(抓数对比)
- [ ] 面板 zone 行、telemetry zone 字段、anchor_log 三个 *_seconds 均正确
- [ ] FIELD_NOW 摘要含 zone;抓包确认 kimi 请求体无 zone/场态字样
- [ ] red_nudge_min=0 时任何情况不推送;=2 时持续 red 2 分钟收到一条,
      且单 session 不重复
- [ ] ?anchor=off 时 zone 层整体关闭(对照回归)
- [ ] fps 下降 ≤2(微光带与召回脉冲均为 uniform/单次绘制,零逐粒子成本)
