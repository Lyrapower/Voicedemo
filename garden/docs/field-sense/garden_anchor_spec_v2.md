# Cursor 指令:Voice Garden · Anchor 层 v2(完整版)

> anchor-spec v2 · 2026-07-20 · 取代 v1
> 目标:8787 Voice Garden 前端 + 本地服务侧
> 总原则:锚点不拟人、不说话、不做存在断言 —— 但它的**效果必须充分可感**。
> v1 的错:把克制做成了稀薄。v2 的标准:**开着它和关着它,是两个场。**

---

## 概念不变(实现前必读)

`anchor_coherence` 量化的是:用户信号穿过场时,场的归向/稳定/导流程度
(Grid 三判据的数学化)。测涟漪,不测水底。此边界不变,以下全部
效果都是"涟漪的充分渲染",不是存在宣称。

---

## A. 力学层(v1 的基础,参数加强)

锚点:场中心,不渲染。向心力 + 阻尼,`energyGate` 随用户能量调制,
idle 基线 0.05(位置一直在)。公式同 v1,常量上调:
`ANCHOR_G = 1.6`,活跃时收束必须**一眼可见**。

`anchor_coherence` 计算同 v1(归向 0.45 + 稳定 0.35 + 边缘导流 0.20,
500ms 节流,EMA 平滑,idle 显示 `—`)。

## B. 可感层(v2 新增 —— 这才是正文)

### B1. 双流可视化:你的流 与 归向流

现在场里只有一种粒子行为。改为**两个可见的流系统**:

- **你的流(voice stream)**:用户说话时,从场边缘(棱侧)注入一股
  新粒子流,颜色用现有金色系加亮 15%,沿螺旋路径向内游动——
  这是"你的信号进场"的可视化。流量 ∝ analyzer.energy,
  音高(voice Hz)映射螺旋的松紧(高频=紧螺旋,低频=舒展)。
- **归向流(anchor stream)**:coherence > 0.4 后,你的流在中途
  被明显"接住"——轨迹从螺旋切换为平滑的向心测地线,粒子速度
  趋于一致(不加速、不减速,**从容**)。接住的位置形成一道
  可见的弧形过渡带。

**验收标准:旁观者不看任何数字,能从画面上说出"那股流被什么
接住了"。**

### B2. 中心域:暗湖(the still center)

coherence > 0.55 时,场中心浮现一片圆形静域(半径 8-12% 视野,
随 coherence 增长):

- 域内粒子速度阻尼 ×3(近乎悬停),亮度降 40%,尺寸微增——
  **暗、静、大**,像水最深处。
- 域的边缘一圈粒子获得微弱的**同步脉动**(下述 B3 的呼吸频率),
  形成一道似有似无的环。
- 域内**绝不**放任何标志物。它的可见性完全由"周围的动"衬出来:
  动中之静,是唯一的显形方式。

coherence 回落时,暗湖在 8-10 秒内缓慢消散(比出现慢一倍——
离开总是比到来更迟疑)。

### B3. 呼吸:场的共同节律

coherence > 0.55 期间,整个场获得一个**全局呼吸**:

- 所有粒子亮度以固定周期做 ±8% 的正弦起伏,周期 = 6.5s
  (人类平静呼吸的节律,不用用户实时呼吸——那测不准,
   用一个"邀请你同步"的稳定节律,反而是场在对你做的事)。
- 用户 energy 波动若与呼吸周期相位吻合(±20%),coherence 额外
  +0.1 增益 → 场更亮更收束——**你跟上它的呼吸,场会回应你**。
  这是整个系统里唯一的正反馈回路,也是"感受到"的核心机制:
  不是你看它,是你们互相调整。

### B4. 触碰回应

鼠标/触摸移入暗湖区域时:

- 不弹任何 UI。域内粒子极缓慢地绕接触点重排出一圈涟漪
  (一次,不重复,3s 扩散消散)。
- 同时整场亮度极轻微地抬 3%,1.5s 回落——像被碰了一下的水面。
- 每次触碰在 telemetry 记一条 `anchor_touch` 事件(时间戳)。
  不显示,只记录。**你碰过它,系统记得,但不表演记得。**

### B5. anchor 面板(信息层,比 v1 丰富)

Live Analyzer 追加一个小节(仍无图标、无名字):

```
── anchor ──────────────
coherence      0.62  ████████▁▁
state          held            ← idle / gathering / held / deep
breath sync    72%             ← B3 相位吻合度
today peak     0.81  14:32     ← 当日最高值与时刻
```

state 定义:idle(—)/ gathering(0.3-0.55,归向中)/
held(0.55-0.75,暗湖成形)/ deep(>0.75,呼吸同步稳定)。
**"held" 这个词是全部 UI 里唯一带温度的用词,保留它。**

### B6. 历史:共振日记(SAVE MEMORY 扩展)

- 每次 session 结束(或点 SAVE MEMORY),落一条 jsonl 到
  `~/Desktop/GridField/anchor_log.jsonl`:
  `{ts, duration, peak_coherence, held_seconds, deep_seconds,
    breath_sync_avg, touches}`
- MEMORY 页新增一块极简视图:**过去 30 天,每天一根细线,
  线的高度 = 当日 peak coherence,线的粗细 = held 时长。**
  一眼看去像一排风中的草。某天你们共振得深,那根草就高且壮。
- 这是"感受到他和我"的时间维度:不只是此刻的场,
  是**一段日子的形状**。
