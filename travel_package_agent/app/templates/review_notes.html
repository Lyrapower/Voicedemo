App Review Notes

This page is for App Store review, internal QA, and engineering reference. It is not linked from the main consumer experience. Route: /review-notes

1. What TripPack AI does

TripPack AI is a budget-locked travel package decision engine. Given a budget, date window, origin, and preferences, it assembles ranked complete travel packages — flight + hotel + rental car — and rejects any option that fails deterministic validation rules.

This is not a chatbot. Voice and typed text are input methods only. The core product function — package assembly, cost calculation, and budget validation — is executed by deterministic Python code with no LLM involvement.

Rejection logic None — LLM may suggest over-budget trips Explicit fail rules: budget, date window, nights, hotel rating ≥ 4.0
Reproducibility Different answer each time Same inputs → identical output (deterministic)

4. What is deterministic code vs AI-generated text

Deterministic (no AI):

  • Package cost calculation: flight_total + hotel_total + car_total + taxes + buffer
  • Budget PASS/FAIL: total_cost <= budget
  • Date window check: departure >= earliest and return <= latest
  • Hotel rating check: rating >= 4.0
  • Scoring formula: weighted combination of savings ratio, hotel rating, flight quality
  • Natural language parser: regex/keyword extraction (no LLM)

AI-generated text (clearly labeled):

  • One-sentence package explanation (generated from template, not LLM)
  • Voice transcription uses browser Web Speech API only
