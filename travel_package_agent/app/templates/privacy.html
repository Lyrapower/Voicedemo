Privacy

Your data stays yours.

TripPack AI is designed to work without collecting sensitive personal information.

V0 Status — Local Only

This version runs entirely on your device. No account is required. No data is sent to external servers. All preferences are stored locally in your browser.

What TripPack AI uses

Trip request inputs

  • Origin city or airport
  • Budget (USD)
  • Travel dates
  • Number of travelers
  • Destination preference
  • Rental car requirement
  • Travel style

These are used only to generate and score travel packages. They are not stored on any server in V0.

Browser localStorage (optional)

If you save a package, it is stored in your browser's localStorage — not on any server. You can clear saved packages at any time.

Saved packages cleared.

What TripPack AI does not need

No contacts No photos No location No login No payment info No health data

Precise location is never requested. Destination preference is entered manually.

Voice input

Optional

Voice input uses the browser's built-in Web Speech API. Audio is processed by your browser — TripPack AI does not receive raw audio.

Voice is entirely optional. You can type your trip request directly and all features work without microphone access.

Notifications (coming in V1)

Price drop alerts — not active in V0

A future version will optionally request notification permission to alert you to price changes. This is not enabled in V0. No notification permission is requested.

Pricing and data honesty

V0 Uses Deterministic Demo Data

All travel packages in V0 are generated from deterministic mock data. Prices are not live. Booking links are placeholders. Do not use these numbers to make real financial decisions.

When live APIs are integrated, copy will change to: "Prices can change at checkout. Final price is confirmed by the booking partner."
