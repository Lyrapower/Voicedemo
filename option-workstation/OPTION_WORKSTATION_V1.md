# OPTION_WORKSTATION_V1 —— 方案纸(拍板稿)

```
================================================================
OPTION_WORKSTATION_V1 · 方案纸
变更记录:v1 2026-07-29(守恒起草,待 Lyra 拍板;批后守恒亲手整包,

【一、宪法(先于一切功能)】
1. 所有数字出自确定性引擎:IV、Greeks、GEX、POP、盈亏平衡、
   情景损益——零 LLM 参与计算。
2. LLM(经 gateway lane)只做两件事:解读读数、七问清单陪审
   (挑战 thesis);永远不给方向,SIGNAL_RE 同闸。
3. 仪表宪法:每格读数带来源+时间戳,陈旧作废不显旧值;
   模型类读数(GEX/Dealer)必须带假设标注——模型不冒充数据。
4. 数据层永不过滤:raw 不可变;清洗只做隔离与标注,不做销毁。
5. 七问为界面的脊柱,不是附件(见【五】)。

【二、架构:城的新区,不是孤岛】
- 服务:option-workstation @ :8620(Docker,与 console 同族)
- 三层:
  a) 数据层  raw store(买断数据落盘,parquet 分区
     underlying/expiry/date)→ 清洗层 → 特征层(RV20/VRP20/
     IVR/IVP/EM),层层版本化、可回放、带谱系戳;
  b) 引擎层  Python 确定性:
     · IV:美式 BAW/CRR 二叉树(离散股息),指数欧式 BS;
       forward/借贷率从 put-call parity 逐到期反推;
     · 曲面:逐到期 SVI,无套利约束,拟合 RMSE 输出为仪表;
     · Greeks 从清洗后 IV 重算;
     · GEX/Net GEX/Gamma Flip:符号假设(dealer 净空客户流)
       与 OI 归因方式上屏标注;
     · 策略引擎:任意腿组合 → 盈亏平衡/最大亏损/POP/
       情景损益矩阵(价格×IV×时间三轴);
       成交现实性:每腿 mid±k×spread 成本,
       「价差成本 ÷ 预期 edge」百分比直接印在策略卡上;
  c) 界面层  单文件前端,DESIGN_SPEC v1(6 级字阶/CJK 禁等宽/
     gold 唯一 accent/横幅 40px/log 折叠)。
- 回放:as-of 光标(EOD 逐日),严格点时——链、报价、IV 全部
  按快照日重建,无前视;退市标的保留(无幸存者偏差)。

【三、数据层定案(拍板点①)】
P0 买断层(一次性,即刻可动):
  首选 databento(OPRA 官方源,按量一次付费、数据永久归你,
  按 symbol×日期切片)——最贴"断续突发式测试"的经济形状;
  备选 CBOE DataShop 官方切片 / HistoricalOptionData 全历史
  EOD 包(retail 级,原型价位)。
  初始宇宙(拍板点②):SPY、QQQ + 提名席标的(与热力同源,
  建议首批 ≤10 只),全历史 EOD 链。
P1 实时层(P0 验收后):券商 API 优先(IBKR/Tradier——
  有账户则实时报价近乎免费,且顺带解决"每腿能否成交"的
  真实盘口核验);Polygon 为无账户备选。
明确不订:Unusual Whales / flow 类(叙事产品,歧义率高,
  不配进七问;若将来有用,走提名席带标限额,属 P2)。

【四、清洗管道(十道工序,每道对应既有判例)】
raw(不可变)
 → 身份归一:OCC 符号规范化;非标合约(乘数≠100/调整合约)
   隔离表,不删,禁入 mid/IV 计算
 → 报价卫生:bid≤ask;去 crossed/locked;零 bid 翼特殊处理;
   陈旧检测(标的动、报价 N 分钟不动);价差% 按 moneyness 分桶限
 → 套利体检:垂直单调、蝶式凸性、parity 残差——违例进隔离表
   带原因码(数据错 or 真实借贷/股息信息,人工可查)
 → 自算 IV(不盲信供应商列)
 → SVI 曲面,RMSE 入仪表(RMSE 红 = 七问第一问直接亮红)
 → 特征层:RV20/VRP20/IVR/IVP(252d 回看)/Expected Move
 → Greeks/GEX 重算,假设上屏
 → 隔离率、陈旧率、RMSE 三格进 pipeline_doctor 同款仪表
验收基准:清洗前后行数对账(raw = clean + 隔离,一行不失踪)。

【五、七问清单 = 界面脊柱】
右侧常驻清单栏,七问各绑真实仪表,绿/琥珀/红:
 1 数据可信?      ← RMSE/陈旧率/隔离率
 2 方向还是波动率? ← 人工勾选 + IV-RV 剪刀差提示
 3 权利金贵否?     ← IVR/IVP/VRP20(展示,不下结论)
 4 Gamma 环境?     ← Net GEX/Flip 位置(带假设标注)
 5 结构表达判断?   ← 策略卡 vs 勾选的 thesis 一致性提示
 6 每腿能成交?     ← spread%、盘口(P1 起真实盘口)
 7 证据足否?       ← 前六问汇总;任一红 → 顶部横幅
   「当前不适合交易」——此结论入日志,与交易同等地位。
「高 IV ≠ 该卖波动率」类护栏文案固化在 UI,不靠自觉。

【六、分期与验收】
P0(首包):EOD 买断数据入库 + 清洗管道 + 回放 + 链/曲面/
  IVR/IVP/RV/VRP/EM + 策略引擎 + 七问清单。
  验收:①复现你举的两个截面级别的卡(POP/盈亏平衡区间/
  IVP/VRP 数字齐全带谱系)②清洗对账零失踪③RMSE 仪表
  红绿可触发④「不适合交易」路径可走通并留档。
P1:实时层 + 真实盘口 + GEX 日内。
P2:提名席接入(与热力动态提名同构)、earnings 日历叠加层。

【七、拍板点】
① 数据首购:databento 切片(按量,可控) / HistoricalOptionData
   全历史包(便宜起步) / CBOE DataShop —— 选一 + 预算档;
② 初始宇宙名单(建议 SPY/QQQ + ≤10 提名);
③ 部署位:先落现有笔记本 Docker,Studio 到货整体平移。
```
