# Service Tiers / Pricing

## Tier 1 - Scopegate Review

- Price: $10,000
- Duration: 1-2 weeks
- Best for: Teams that need a fast technical/product audit and a clear implementation plan before committing to a build.
- Includes:
  - 1 system/workflow review
  - risk and scope boundary map
  - local-first architecture recommendation
  - build/no-build decision
  - acceptance criteria
  - 1 delivery brief
  - Exit Kit Lite
- Does not include:
  - production deployment
  - wallet/key handling
  - smart-contract audit
  - ongoing support

## Tier 2 - Proof Pack Pro

- Price: $30,000
- Duration: 3-4 weeks
- Best for: Teams that need a working proof-backed implementation or investor/demo-ready delivery pack.
- Includes:
  - scoped implementation
  - proof report
  - local acceptance command
  - deployment checklist
  - operator notes
  - demo walkthrough
  - handoff artifacts
  - Exit Kit Pro
- Does not include:
  - custody
  - trading execution
  - legal/compliance opinion
  - production treasury permissions

## Tier 3 - Integration Partner / Retainer

- Price: Starting at $12,000/month
- Commitment: 3-month minimum
- Best for: Teams that need continuous iteration, investor demos, grant delivery support, or evolving AI infrastructure after the first proof pack.
- Includes:
  - monthly review window
  - update planning
  - approved implementation updates
  - proof report refresh
  - deployment checklist refresh
  - handoff notes
  - priority repair window

Crypto infrastructure changes quickly. A one-time build is often not enough once a team starts testing with users, investors, grants, validators, integrations, or protocol partners. The retainer tier exists for teams that need controlled iteration without turning the system into an untracked patch pile. Every approved update must remain scoped, documented, and proof-backed.

These prices reflect infrastructure delivery, not audit-level advisory. If your project scope is smaller than a Scopegate Review, we'll tell you directly - no inflated packages.
