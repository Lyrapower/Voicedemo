# Crypto Module FAQ

## Q1: Do you need access to our wallets or private keys?
No. The default scope does not require wallet custody, private keys, seed phrases, or treasury access. If a workflow ever touches high-risk execution, it must be explicitly scoped and human-approved. The baseline service is infrastructure, proof, workflow, and handoff - not custody.

## Q2: Is this a smart-contract audit?
No. This is not a formal smart-contract security audit. The work can include workflow risk mapping, integration boundaries, and proof-backed delivery, but contract-level security review must be handled by qualified auditors.

## Q3: Can you deploy directly to production?
Only if the scope, environment, access boundaries, and approval process are explicitly agreed. The default recommendation is Local Proof first, then Private Cloud or Client Infrastructure after the proof is verified.

## Q4: Can this use OpenAI, Claude, Qwen, or other external models?
Yes, but external model/API usage must be opt-in, budgeted, logged, and kill-switchable. The default posture is local-first or external-off until approved.

## Q5: What makes this different from a normal AI automation agency?
The delivery is scope-gated, proof-backed, and designed around crypto-specific risks: custody boundaries, public reputational exposure, token/protocol context, external API control, and verifiable handoff.

## Q6: What do we receive at the end?
Depending on tier, the client receives a delivery brief, repo/files, run instructions, acceptance command, proof report, deployment checklist, operator notes, and Exit Kit.

## Q7: Can you help with grant or hackathon delivery?
Yes. This is one of the strongest fits. The system can be packaged as proof-backed implementation, demo flow, and handoff materials for grant/hackathon review.

## Q8: Do you provide legal or compliance advice?
No. This service does not provide legal, regulatory, tax, or compliance opinions. If the workflow touches regulated activity, the client must involve qualified counsel.

## Q9: Can the system trade, move funds, or execute on-chain actions automatically?
Not by default. The default service does not include autonomous fund movement or trading execution. Any high-risk action must be explicitly scoped, human-approved, logged, and separated from advisory or analysis workflows.

## Q10: How fast can a first proof be delivered?
Scopegate Review is designed for fast review. Proof Pack Pro timing depends on scope, but the work should stay narrow enough to verify with a clear acceptance command and proof report.

## Q11: What if you stop operating the business?
Exit Kit is given at handoff, not at end of relationship. Every paid tier ends with you having full ownership and the ability to run, modify, or replace the system without our involvement. If we disappear tomorrow, you still have everything.
